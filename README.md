# Combinatta — Páginas públicas

Este repositório contém páginas públicas relacionadas ao Combinatta, incluindo a Política de Privacidade e, futuramente, Termos de Uso e informações institucionais.

O Combinatta é uma extensão Chrome criada para auxiliar na organização e análise manual de bolões das Loterias Caixa.

## Páginas disponíveis

- [Política de Privacidade](./privacy.html)

## Sobre o Combinatta

O Combinatta é uma ferramenta assistiva/manual. A extensão não realiza apostas, não efetua pagamentos, não adiciona itens ao carrinho, não finaliza compras e não preenche dados automaticamente no site da Caixa.

As análises têm finalidade organizacional e informativa, sem promessa de ganho ou garantia de resultado.

## Código da extensão

Este repositório não contém o código-fonte da extensão Combinatta.
