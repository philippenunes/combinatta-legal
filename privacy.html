Combinatta

Política de Privacidade

Última atualização: 28 de maio de 2026

O Combinatta é uma extensão para navegador Chrome criada para auxiliar na organização e análise manual de bolões das Loterias Caixa.

Esta Política de Privacidade explica quais informações são utilizadas pela extensão, como elas são armazenadas e quais são os limites de uso desses dados.

1. Informações utilizadas pela extensão

O Combinatta pode ler informações visíveis nas páginas das Loterias Caixa relacionadas aos bolões exibidos ao usuário, como:

  • números das combinações;
  • dados dos bolões visíveis na tela;
  • quantidade de combinações;
  • valores exibidos na página;
  • informações usadas para identificar repetições e cobertura;
  • status definidos manualmente pelo usuário, como comprado ou pendente.

Essas informações são utilizadas apenas para organizar, exibir e analisar os bolões dentro da própria extensão.

2. Informações que não coletamos

O Combinatta não coleta, solicita ou armazena intencionalmente:

  • nome;
  • CPF;
  • e-mail;
  • telefone;
  • endereço;
  • dados bancários;
  • dados de cartão de crédito;
  • senhas;
  • dados de login;
  • informações de pagamento;
  • documentos pessoais;
  • dados sensíveis do usuário.

3. Armazenamento local

Os dados da análise são armazenados localmente no navegador do usuário, usando recursos de armazenamento da própria extensão, como chrome.storage.local.

Esses dados permanecem no dispositivo do usuário e não são enviados para servidores do desenvolvedor.

4. Compartilhamento de dados

O Combinatta não vende, aluga, transfere ou compartilha dados do usuário com terceiros.

A extensão não possui backend próprio e não envia os dados capturados para serviços externos.

5. Uso das permissões

O Combinatta solicita permissões apenas para executar suas funcionalidades principais:

  • acessar páginas específicas relacionadas às Loterias Caixa, para permitir a captura assistida dos bolões visíveis;
  • usar armazenamento local, para manter a análise, os bolões capturados e os estados definidos pelo usuário.

As permissões são utilizadas somente para fornecer as funcionalidades descritas nesta política e na página da extensão.

6. Compra manual

O Combinatta é uma ferramenta assistiva e manual.

A extensão não realiza apostas, não efetua pagamentos, não adiciona itens ao carrinho, não finaliza compras e não preenche dados automaticamente no site da Caixa.

O usuário é responsável por conferir todas as informações no site oficial antes de tomar qualquer decisão ou realizar qualquer compra.

7. Ausência de promessa de resultado

As análises do Combinatta têm finalidade organizacional e informativa.

A extensão não garante prêmios, não promete ganhos e não assegura aumento de chances de acerto.

8. Exclusão dos dados

O usuário pode remover os dados armazenados pela extensão usando a opção de limpar análise dentro da própria extensão.

Também é possível remover todos os dados da extensão desinstalando o Combinatta do navegador.

9. Alterações nesta política

Esta Política de Privacidade poderá ser atualizada para refletir melhorias na extensão, mudanças legais ou alterações nas práticas de privacidade.

A data da última atualização será indicada no início deste documento.
